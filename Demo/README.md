# WebMarkdownEditor demo

This DataFlex 26.0 WebApp demonstrates the reusable Markdown editor and viewer
from the sibling `Library` workspace.

Build it from this folder with:

```text
df-cli build "WebMarkdownEditor Demo.sws" --rebuild
```

The demo's `AppHtml/Index.html` shows the required browser includes. In a
consuming application, install the library package instead of copying the demo
workspace.
